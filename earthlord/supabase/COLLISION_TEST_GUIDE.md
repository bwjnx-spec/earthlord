## 🧪 步骤2：测试碰撞检测

### 测试场景1：起始点检测（在领地内开始圈地）

**操作**：
1. 在应用中走到测试领地内部（坐标范围内）
2. 点击「开始圈地」按钮

**预期结果**：
- ❌ 圈地被阻止
- 🔴 显示红色横幅："不能在他人领地内开始圈地！"
- 📳 触发错误震动
- ⏱️ 3秒后横幅自动隐藏

### 测试场景2：距离预警（逐步靠近领地）

**操作**：
1. 在领地外围（>100m）开始圈地
2. 逐步向领地方向移动

**预期结果**：

| 距离范围 | 横幅颜色 | 提示消息 | 震动 |
|---------|---------|---------|------|
| > 100m | 无 | 无 | 无 |
| 50-100m | 🟡 黄色 | "注意：距离他人领地 Xm" | 轻震 1次 |
| 25-50m | 🟠 橙色 | "警告：正在靠近他人领地（Xm）" | 中震 2次 |
| < 25m | 🔴 红色 | "危险：即将进入他人领地！（Xm）" | 强震 3次 |

**检测频率**：每 10 秒检测一次

### 测试场景3：路径穿越检测（轨迹穿过领地边界）

**操作**：
1. 在领地外开始圈地
2. 移动轨迹穿过领地边界

**预期结果**：
- 🛑 圈地自动停止
- 🔴 显示红色横幅："轨迹不能穿越他人领地！"
- 📳 触发错误震动
- ⏱️ 横幅保持5秒后自动隐藏

### 测试场景4：路径点进入检测（走进领地内部）

**操作**：
1. 在领地外开始圈地
2. 直接走进领地内部

**预期结果**：
- 🛑 圈地自动停止
- 🔴 显示红色横幅："轨迹不能进入他人领地！"
- 📳 触发错误震动
- ⏱️ 横幅保持5秒后自动隐藏

## 🔧 调试技巧

### 查看日志

在 Xcode 控制台中查看碰撞检测日志：
```
[INFO] 起始点安全，开始圈地
[INFO] 碰撞检测定时器已启动
[WARNING] 距离预警：注意，距离 80m
[WARNING] 距离预警：警告，距离 40m
[WARNING] 距离预警：危险，距离 20m
[ERROR] 路径碰撞：轨迹穿越他人领地边界
[INFO] 碰撞违规，自动停止圈地
```

### 验证领地数据

在 Supabase Dashboard 的 Table Editor 中查看 `territories` 表：
```sql
SELECT id, name, area, point_count, is_active, created_at
FROM territories
WHERE name = '测试领地-橙色';
```

### 删除测试领地

测试完成后，可以删除测试领地：
```sql
DELETE FROM territories
WHERE user_id = '00000000-0000-0000-0000-000000000001'
  AND name = '测试领地-橙色';
```
